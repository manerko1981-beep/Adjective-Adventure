Block-based structure

Standard for every interactive

1
Real activity

Not a description. HTML/JS must actually work.

2
Visual finish

Age-appropriate design, images/icons where useful, animation and feedback without clutter.

3
Holst-ready

Published URL checked, responsive layout, readable inside an iframe.

4
Productive follow-up

CLICK → READ → EXPLAIN/TRANSLATE → SAY/MAKE A SENTENCE.

Publishing pattern

lesson-interactives / course / lesson / activity / index.html

Example: lesson-interactives/spotlight4/pre01/reading-grammar/index.html. Existing test remains at its current path and can be reorganised later without losing the working proof-of-concept.
